# NATURALIZE – Personalized Skin & Hair Care System

## Project Overview

NATURALIZE is a web-based personalized skin and hair care system that provides users with natural-care recommendations based on their individual skin and hair concerns.

The project focuses on providing a simple, user-friendly platform where users can enter their personal care requirements and receive relevant natural-care guidance.

## Key Features

- Personalized skin-care recommendations
- Personalized hair-care recommendations
- Skin concern selection
- Hair concern selection
- User-friendly web interface
- Structured recommendation system
- Database-backed application

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Templating:** Jinja
- **UI:** Bootstrap

## Project Workflow

User Input → Concern Selection → Data Processing → Recommendation Matching → Personalized Natural-Care Guidance
